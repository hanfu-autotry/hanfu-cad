# 05 接口文件（`interface_*.json` 怎么读、参数怎么回填）

> harness 与桌面程序之间**只有这一个交接物**。桌面程序不做识别、不做判级；它把状态打包成 JSON，你读它、改它、再交回来。

## 谁生成、放在哪

- 生成：`hanfu-studio` 顶栏「逆向 / 许愿 → 接口文件」→ 按钮「导出接口文件给 harness」。
- 代码：`adapters.interface_file(kind, request=..., artifact_path=..., pid=..., size=..., sex=..., overrides=..., components=...)`
- 位置：`hanfu-studio/out/interface/interface_<reverse|wish>_<MMDD-HHMMSS>.json`
- 导出后路径会自动复制到剪贴板。

## 字段

| 字段 | 含义 | 你要不要改 |
|---|---|---|
| `schema` | `hanfu-studio/interface@1` | 不改 |
| `created` | 生成时间 | 不改 |
| `task.kind` | `reverse`（实物/官图）或 `wish`（一句话需求） | 不改 |
| `task.request` | 你填的需求原文 | 不改（这是原始输入） |
| `task.artifact_path` | 逆向时：官图/实物路径（或你填的说明） | 可补 |
| `pattern.id / label / cut / project / script` | 当前选中的版型与它的程序位置 | 不改 |
| `pattern.run` | **调用接口**：`kind`（make/params）＋ `argstyle` 或 `fixtures` | 不改（这是事实） |
| `pattern.modes` | 可复用模式（基准档/夹具），含说明 | 加模式时改 `patterns.json` |
| `pattern.knobs` | 界面上的旋钮（key/label/min/max/step） | 不改 |
| `pattern.size / sex / params` | **当前界面状态**（含你已改的参数） | **主要看这里** |
| `components` | 当前裁片清单（名字） | 不改 |
| `library` | 共享库引用（若有） | 不改 |
| `gates` | 该版型该跑的 4 道闸门及命令 | 不改 |
| `conventions` | 设计目的 / 两个入口 / 判级三档 / 继承规则 / 拟合边界 / 禁止项 | 不改（这是规矩） |
| `workspace` / `log` | 工作区根、软件日志路径 | 不改 |

## 你要做的事

### A. 拿到 `kind=wish`（许愿）

1. 读 `task.request`，按 `02-许愿手册.md` **先判级**。
2. 读 `pattern.run` 决定怎么落地：
   - `kind=params` → 在 `fixtures` 里加一组（参数级），或直接给 `pattern.params` 里的旋钮换值。
   - `kind=make` → 号型表/放量档/基准档里改（见 `pattern.modes`）。
   - 判成结构级/裁法级 → 不看 fixtures，按 `02` 第 2/3 步建新程序。
3. 跑闸门（`gates` 里有命令），把结果写进交付说明。

### B. 拿到 `kind=reverse`（逆向）

1. 读 `task.artifact_path`，按 `03-逆向手册.md` 量图（投影法 + 一图一标定）。
2. 量出的数**回填成夹具**（不要直接改 DEF，除非人签字）：
   - 通裁：`pattern.run.fixtures[<模式>] = {"L_BODY":…, "GARMENT_L":…, …}`
   - 分裁：改 `sizing.py` 的基准表 / 传 `--ease` `--profile`
3. 跑 `gates` 里的参照闸门（叠合/核对表），确认 IoU 与 FAIL 数。

## C. 回填给桌面程序的两种方式

1. **改注册表**（持久）：`hanfu-studio/patterns.json` 里该版型的 `run.fixtures` / `modes`，
   然后跑一次 `python kit/scripts/build_kit.py` 让 `01-版型清单.md` 同步。
2. **临时载入**（不落盘）：把参数 JSON 粘进 studio 的「逆向 / 许愿 → 接口文件」面板的文本框即可
   （面板会解析并重新出图）。

## D. 约定

- **接口文件是快照**，不是命令队列；一次任务一个文件，别复用。
- `params` 里的键必须存在于该版型的 DEF 或夹具里，否则脚本会忽略（不会报错）。
- 你**不要**往接口文件里写"几何"：几何永远只在版型程序里。
