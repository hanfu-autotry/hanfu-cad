## 一、古制（`hanfu-shenyi`）构造口径

1. **上衣下裳是两件事**：上衣一块布、裳另一块布（同料、同样拼幅）；
   **缝到腰线上才叫深衣** → 腰线是**接缝（seam）**，不是折线。
2. **上衣**：宽＝通袖（4 幅 × 幅宽），高＝前衣长＋后衣长；
   **水平中线对折＝肩线**（横的，不剪）。
3. **袖＝这块布的两个端头**（连袖，不是接袖）；袖底下沿折后与自身镜像缝成袖筒；
   袖底缝＝**幅缝 → 袖口**（外幅整条）。
4. **后领**：由**领条**绕过颈后立起（不是"折出来的后领"）。图注里那个**梯形＝领条**。
5. **幅数**（用户 2026-11-04 定案）：中段（上衣）**4 幅** = 通袖 2000；
   **V3 窄袖便服：上/下段各 2 幅** = 1000（直筒窄摆）；**V2 宽袖礼服：各 3 幅** = 1500（摆 1080 够走路）。
   布片在**腰线处是台阶**（裳比衣窄 500 或 250／侧），不是一整块等宽布。
   参数 `N_SHANG`（`_DEF` 默认 2；V2 在 `patterns.json` 的夹具里覆盖成 3），
   **布片/区块/整衣 DXF 三处同源读取**。
   **摆宽受布幅约束**：`HEM_HALF = min(要的摆半宽, 幅宽×N_SHANG/2)`——2 幅时上限 500，3 幅时 540 可用。
6. **领条折转段**：恒为「**两个领条三角 + 后领方形**」三件（三角底边 = 开口半宽 − 后领半宽，
   高 = 折转露出高；后领方 = 2×后领半宽 × 折转高）。开口/压边怎么调都不许翻，后领半宽必须 < 开口半宽。
7. **前中**：**剪开贯通**（±80 两道剪开、中间 160 直边缺口挖掉）→ 两襟独立可滑。
8. **背中缝是竖的**（拼幅缝），与肩线折线只交一点。
9. **裳收褶**：真实存在；**平铺图上画、DXF 不画**（DXF 不做褶几何，只在标注写差值）。
10. **DXF 口径（方案 B）**：整衣铺开一片，**一条连续闭合外轮廓 + 标注**；不切成独立裁片、不要"两片各自闭合"。
11. **组件 ≠ 闭合裁片**：组件是同一片布上被缝线/折线划出的**功能区域**，彼此**共用边界**。

## 二、默认（`hanfu-cad` / `hanfu-jiexiu`）判据

- 前中是**门襟越中**（`LAP_DX = 交叠/2`），不是开口贯通。闸门判据用「门襟越中量」。
- 接袖版必须有 **接袖片 ×4**（前后各二）；半臂**没有**独立袖片（袖并入衣身）。
- 两档基准不要混：`artifact`（文物基准，女装默认）／`vendor`（厂商号型表，男装默认）。

## 三、术语：领 / 襟 是两个轴（别硬造二选一）

- **领**＝领口形：**交领**（两领缘斜下、胸前交叉成 y/X）／**直领**（两缘平直沿前襟而下、平行）／圆领·立领。
- **襟**＝前身开合：**交襟**（两襟叠压、右衽）／**对襟**（正中相对、不叠压）。
- **这四个词不是一个划分**：平铺既可以是直领也可以是交领，穿上也一样。

### ★ 直交一体（最关键的一条）

**"交"不是分类，是一个连续量——左右衣襟的交叠程度。**
交叠=0 → 直领；浅 → v 形；深 → y 形；更厚 → x 形。
**裁片上没有"交"**：前襟缘永远是直的（这才是"直领"的所指）；**"交"是系出来的**（交襟＝把两襟交叠着系）。
所以问"这是直领还是交领"**问错了对象**——它问的是状态，而这件衣是能在两个状态之间滑动的同一件衣。
"左右衣襟活动"＝前中必须剪开贯通。

### 直领 ≠ 矩领（且本版型不是矩领）

- **直 / 矩 是两个轴**：直说的是**曲直**（前襟缘不弯）；矩说的是**方圆/直角**（"曲袷如矩以应方"）。
- **矩领的真身**：前中开一个**矩形豁口**——左右领口各剪去一段、留出两条竖直直边，
  两块领条夹着这个矩形（用户 2026-11-04 给图确认）。那是**另一种领型**，**本项目不做**。
- 我们这件是：**直领交襟**——前襟缘直、前中剪开贯通、领条在领口处上折；
  折转段恒为「**两领条三角 + 后领方形**」。**不要再用"矩领"描述它。**

## 四、黑名单（这些说法**不许再用**）

| # | 错误说法 | 为什么错 |
|---|---|---|
| 1 | "交领 / 直领 互斥" | 是同一个量的读数，不互斥 |
| 2 | "交领 + 对襟 不存在" | 自己编的假规则 |
| 3 | "裁片上是直领、穿上才是交领"（裁/穿二分） | 太脆，两词在两态都能成立 |
| 4 | "掖完之后缘没变弯，所以仍是直领" | 在身上那条缘**必然弯** |
| 5 | "平铺也是交领，因为两缘在颈后相接" | **相接 ≠ 相交** |
| 6 | 拿"一掖一压"解释**平铺** | 掖压是穿的动作，平铺上没有 |
| 7 | "把裳折上来" | 裳是**另一块布**，缝合在腰线上 |
| 8 | "前中挖掉一块"当折边/贴边 | 前中是**剪开贯通**，两襟独立可滑 |
| 9 | "后领是折出来的" | 后颈由**领条**绕过立起；梯形是领条 |
| 10 | "两片各自闭合"画整衣 DXF | 方案 B：**一条连续闭合外轮廓** |
| 11 | 目测估数、跨图套比例 | 必须投影法 + 一图一标定 |
| 12 | 用收褶量/摆宽/腰宽自己编 | 必须量+标定，或来自既有 DEF |

## 五、各项闸门判据（按裁法分开，别抄）

| 项 | 默认 | 古制 |
|---|---|---|
| 前中 | 门襟越中 `LAP_DX`（半臂/接袖 135） | 前中开口 160 贯通（±80） |
| 特征件 | 接袖 ×4（接袖版）；无独立袖片（半臂） | 领条 ×1；幅缝/背中缝 |
| 幅数 | 按号型表 | 通袖 = 4 幅 × 幅宽 |
| 有原型闸门 | 叠合（archive/v3 作根）+ verify | 剪裁图对照 + 整衣 DXF 自检 |
| 无原型闸门 | 自洽 + Δ 对账 + 人审签收 | 同左 |

工程可行性四项（两类共用）：**轮廓闭合+无自交 / 最小曲率半径 / 缝线等长·明示收褶 / 幅宽约束**。
**失败不硬打回**：报错示意 + 人工确认放行（写 `signoff.json`）。
