# harness 素材包 · 汉服 CAD 打版

> 这是**给 harness（AI 会话）用的素材包**，不是第二个项目地基。
> 里面只有：索引、手册、命令、机器可读摘要、闸门记录。
> **没有任何版型源码、几何数据、DSL。** 版型程序仍在各自项目里，一个字节都不复制。

## 你要做的事只有两件（外加一件手工）

| 入口 | 谁做 | 在哪做 | 产物 |
|---|---|---|---|
| **手工编辑** | 人 | `hanfu-studio` 桌面程序（选型/参数/预览/排料/CAD 协同） | SVG / DXF / 布局工程 / 排料 DXF |
| **逆向** | harness（你） | 读 `03-逆向手册.md`，改各项目的 `pattern/*.py` 与夹具 | 版型程序初值 + 闸门报告 |
| **许愿** | harness（你） | 读 `02-许愿手册.md`，先判级再动手 | 换夹具 / 派生程序 / 新谱系根 |

两个入口都**不是**自动化流水线：**判级、量图、派生由你（AI）做**；桌面程序只承载状态与出图。

## 阅读顺序（别乱）

1. `01-版型清单.md` —— 现在有哪几个版型、脚本在哪、接口怎么调、闸门跑什么。**（脚本生成，勿手改）**
2. `02-许愿手册.md` —— 拿到一句话需求时按这个判级与执行。
3. `03-逆向手册.md` —— 拿到实物/官图时的量图与回填流程。
4. `04-口径清单.md` —— 形制口径与**术语黑名单**。**动手前必读，这里写的是已经被用户纠正过的结论。**
5. `05-接口文件.md` —— studio 导出的 `interface_*.json` 怎么读、参数怎么回填。
6. `patterns/<id>.json` —— 单个版型的机器可读摘要（脚本/接口/模式/闸门/参考图/文档清单）。
7. `gates/<id>.md` —— 该版型闸门命令与最近一次实测结果。
8. `projects/<项目>/INDEX.md` —— 项目内的脚本与文档索引。
10. `sources-索引.md` —— **素材本体索引**；图就在 `kit/sources/<对象>/<类型>/`：**对象＝这是哪件衣/哪座墓的参考**（01 无锡钱樟夫妇墓 / 02 深衣 / 03 原始直领交襟衣 / 04 直交一体 / 99 待考），**类型＝官图 / 剪裁与平铺 / 三步图 / 号型放码 / 打版草稿 / 证据**；每个对象带 `INDEX.md`，全量出处与 sha1 见 `MANIFEST.csv`；新建版型会自动多出一个对象目录（`kit/subjects.json` 可编辑；它**不在** sources/ 里，重建不会冲掉），全量清单见 `kit/sources/MANIFEST.csv`。

9. **`sources/` —— 素材库本体（分门别类，harness 也往这里放）**：
   入口 `sources/README.md`；七类目录（01 官图 / 02 剪裁与平铺 / 03 实物 / 04 证据 / 05 号型 / 06 草稿 / 99 待考）
   各自带 `INDEX.md`（文件→来自哪个项目→原始路径）；全量出处与 sha1 见 `sources/MANIFEST.csv`；
   新素材投 `sources/intake/`（规矩见 `intake/README.md`）。

## 一次出齐（父程序侧）
`python hanfu-studio/batch_cli.py all`（或界面「批量生成」）：每个可复用模式各出一整套
（SVG/裁片/DXF/尺码表/形制核对），产物在 `hanfu-studio/out/batch/*/`，清单是 `批量清单.md`。
给 harness 的接口文件仍在 `out/interface/`。

## 三条铁律（违反就重做）

1. **不复制源码**：派生新版型只能"取用父版型的片"或"用 Δ 改参数"，**禁止拷贝父版型的 .py 再改常量**。
2. **不自编数**：任何收褶量/摆宽/腰宽/通袖都必须从 `sources/` 图量出来并给出标定，或来自既有 DEF/夹具。
3. **不造引擎**：不合并成万能参数化引擎、不用 YAML-DSL 描述版型、不造自动化的许愿流水线（v0.2 因此被删过）。

## 保鲜

机械部分（01 / patterns / gates / projects / **sources 素材镜像 + 索引**）由脚本重建：

```bash
cd hanfu-studio/kit
python scripts/build_kit.py
```

手写部分（README / 02 / 03 / 04 / 05）**只在口径变更时改**，改完请在 `04-口径清单.md` 末尾记一条变更。
