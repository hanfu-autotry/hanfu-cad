## 规矩（四条）

1. **先归对象**：这张图是哪件衣/哪座墓的参考？新建的版型就新建一个对象（`subjects.json` 加一条）。
2. **再归类型**：官图 / 剪裁与平铺 / 三步图 / 号型放码 / 打版草稿 / 证据。
3. **必须登记**：`MANIFEST.csv` 加一行；能直接量锚定的写 `YES`，只能定性的写 `NO`。
4. **不覆盖**：同名加 `_v2` 并列；重跑 `build_kit.py` 只重建 INDEX，**不清空 intake/**。
