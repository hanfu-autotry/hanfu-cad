# 03 逆向手册（指令式 · 给 harness 读）

> 输入：实物照片 / 博物馆官图 / 剪裁图 / 平铺图。
> **图在 `kit/sources/<对象>/<类型>/`**（对象＝哪件衣/哪座墓的参考；类型＝官图/剪裁与平铺/三步图/号型放码/打版草稿/证据）；
> 用途一览见 `sources-索引.md`，全量清单 `kit/sources/MANIFEST.csv`。
> 输出：**版型程序的初值**（DEF 或夹具）+ 闸门报告。三条铁律：不复制源码、不自编数、不造引擎。

---

## 第 0 步 · 先判"能不能叠合"

**叠合的前提**：图里那件衣与你手上的版型是**同一件**。

- 若图是"含接袖的原尺寸件"（如丝博官图，通袖 2180），而你的版型是半臂（通袖 1650）→ **前提不成立**，
  只能做"形制核对"，不能做像素叠合。
- 判断方法：量图里的通袖/幅数与版型 `resolved` 的值比；差 > 1 幅就换叠合根，别硬叠。

> 历史教训：`overlay.py` 曾把配准锚硬编码成 2180，而现役 `build.py` 是半臂（1650），
> 结果 IoU 只有 0.72 还各向异性 12%。把叠合根换成 `archive/v3`（含接袖原尺寸）后是 **正视 0.8793／背视 0.8996**。

---

## 第 1 步 · 量图（不许目测，全部投影法）

1. **找锚定量**（可换算成 mm 的数）：通袖、衣长、摆宽、交叠量、袖口、幅宽（一匹布）。
2. **标定比例**：`mm/px = 锚定 mm ÷ 该锚定在图上的 px`。一图一标定，**不要跨图套用**。
3. **量线用投影法**（不要靠眼睛估）：
   ```python
   import numpy as np; from PIL import Image
   a = np.array(Image.open(src).convert("L")); dark = a < 120
   cols = dark[y0:y1, x0:x1].sum(axis=0)          # 竖线：列投影
   rows = dark[y0:y1, x0:x1].sum(axis=1)          # 横线：行投影
   ```
   阈值取窗口高度的 0.7~0.9；密集区先放大看再定量。
4. **记出处**：每个数都要能回答"从哪张图、哪条线、多少 px 量的"。写进交付说明。

---

## 第 2 步 · 八条标准锚定（缺哪个就说明缺哪个，别猜）

| 锚定 | 含义 | 用在哪 |
|---|---|---|
| 通袖 | 两袖口之间的总宽 | 决定幅数、插值比例 |
| 衣长 | 肩线→下摆 | 裁片高度、袖肥（古制里 衣长=袖口=袖肥） |
| 摆宽 | 平铺下摆总宽 | 侧缝斜度 |
| 交叠 | 两襟重叠量 | 门襟越中量 `LAP_DX = 交叠/2` |
| 袖口 | 袖口净平开口 | 袖型 |
| 腋深 | 腋点距下摆/肩线 | 侧缝起点、袖底弧 |
| 门襟偏 | 门襟斜边与竖直线夹角 | 前片 grain / 前襟几何 |
| 起翘 | 下摆后端抬起量 | 前后摆弧 |

> 表里任何一项**不确定**就写"未定"，不要用"看起来像"。用户会检查这一步。

## 第 3 步 · 回填到哪里

- **默认**（`hanfu-cad` / `hanfu-jiexiu`）：改 `pattern/sizing.py` 的基准表或 `pattern/build.py` 的 `_DEF`。
  改完必须能跑出 `sizing.summary()`（它会把关键尺寸打出来自证）。
- **古制**（`hanfu-shenyi`）：改 `pattern/build_shenyi.py` 的 `_DEF`（或加夹具），
  产物是 `①材料 ②制作 ③平铺 ④领条` 四段图 + 整衣 DXF。
- **不要**直接改"拟合建议值"；`fit.py` 只出建议，改 DEF 要人签字。

---

## 第 4 步 · 跑闸门（按顺序）

```bash
cd <ws>/hanfu-cad
python verification/overlay.py front back   # 1) 叠合（IoU / precision / recall / 各向异性）
python verification/verify.py               # 2) 形制核对表（尺寸回读 + 结构 + 形制判据）
python verification/fit.py                  # 3) 形状拟合（**只写 suggestions，不改 DEF**）
python verification/report.py               # 4) 重写比对报告（含摆宽敏感度）
cd <ws>/hanfu-jiexiu && python verification/verify.py
cd <ws>/hanfu-studio && python selftest.py  # 5) 全链路
```

拟合边界（**用户定的，不许放宽**）：
1. 只允许**纯形状自由度**（白名单 `META["fittable"]`；能直接量或已锚定的量不进白名单）。
2. 只出**建议值**，不改 DEF。
3. 多闸门同时满足：IoU ↑、p95 不变差、单视不退化 > 0.01、锚定全绿。
4. 正/背视图**共用一组参数**（不许分视图各拟合一套）。

---

## 第 5 步 · 判"对不对"

- **叠合**：IoU ≥ 0.85 合格；各向异性 ≤ 2% 说明"图是等比的"，否则先怀疑标定而不是版型。
- **形制核对表**：0 项 FAIL；被 WARN 的项要能说出"差多少、为什么"。
- **残差归因**：把残差按面积排序，逐条写"是作图误差 / 是标注不同源 / 是模型错"。**不许一句"基本吻合"糊过去。**

## 交付检查表

- [ ] 标定：`mm/px` 是多少、用哪个锚定量算的。
- [ ] 八条锚定逐条给值 + 出处（图名 + 行/列投影结果）。
- [ ] 改了哪些文件（DEF 字段 / 夹具键），**没有复制任何父版型源码**。
- [ ] 闸门四条命令的输出摘要（IoU / FAIL 数 / 建议值 / 自检）。
- [ ] 残差归因表（面积排序）。
- [ ] 未定项列出来（哪一项没量到、为什么）。

## 禁止清单

- ❌ 目测估数（必须投影法 + 标定）
- ❌ 跨图套用比例（一图一标定）
- ❌ 用拟合结果直接改 DEF（要人签字）
- ❌ 把"文物档"的参数挪到"厂商档"（两档不同源）
- ❌ 拿"通袖不匹配"的图硬做像素叠合
