# shiyan-shuling · 试验竖领浅交襟（默认口径 · 试验版型）

**试验性质**：以厂商基准半臂为底，用「一步一画」逐步构造一个**竖领浅交襟**前片 + 领子 + 领条，
第 6 步定稿为「**一条带状领子**」。**尚未注册到 `hanfu-studio/patterns.json`**（没有 `make.py` 契约入口），
当前以 `pattern/step6.py` / `pattern/save_template.py` 出图与落模板。

```bash
python pattern/step6.py           # 第 6 步定稿：完整裁片 5 片 + 领条一条带（26 项自检）
python pattern/save_template.py   # 落模板 pattern/_tpl.pieces.json + _tpl.svg（11 项自检）
python pattern/step3.py … step5.py # 各步单独复跑（27 / 28 / 26 项自检）
```

## 一、几何链（第 1–6 步，全部解析、不量图）

| 步 | 做什么 | 关键量 |
|---|---|---|
| 1 | 解析构造 P₁、P₂（a、b 待定） | `P₁(a)=V+a·(−1,0)`、`P₂(b)=V+b·u_lap`，2×2 线性方程组求交 |
| 2 | 赋值 | `VP₁=VP₂=50mm` ⇒ a=b=50；P₁=(−50,770)、P₂=(8.634531,720.751194) |
| 3 | P₁P₂ 作「新领口」 | **圆心角 60° 弧**：R=弦长=76.5732、矢高 10.2589、弧长 80.1873；两段弧在中缝交于 y=722.8002 |
| 4 | 上领子（等高 30mm 连续竖起） | A=P₁+30·mirror(w)=(−44.8193,799.5493)、B=P₂+30·w=(3.4538,750.3005)；竖起 29.5493、A—A′=89.6386 |
| 5 | 领子按衣片分三块 | 左襟 2110.744392 / 后片 2801.841829 / 右襟 2110.744392，总 7023.330613 mm² |
| 6 | 根据共边做成**一条带状** | 8 条边（2 C + 6 L）、共边 2×30、端头 2×30（分开 230.334）、自交 0、bbox 229.2×109.3 |

## 二、领条：一条带状，由三部分组成

- **三段**：①前片左襟 → ②后片 → ③前片右襟，沿共边 **P₁A / P₁′A′**（各 30mm）相接。
- **首尾不接**：两端 **P₂B / P₂′B′**（各 30mm）分开落在带子两端，间距 230.334mm，**不绕成环**。
- **展开方式**：沿共边依次**翻折（刚性铰接）**——段① 不动、段② 关于 P₁A 反射、段③ 两次反射。
  反射是等距变换 ⇒ 每段边长 / 角度 / 面积**严格不变**，无拉伸、无近似。
- **不自交**（自交点 0）：三段沿 x 依次排开，只在共边处相接。
- 轮廓 `cmds` 仅 `M/L/C/Z`，曲边是三次贝塞尔 `C`（`k=4/3·tan(Δθ/4)`，与 `sheet.py` 出图定义一致）。

## 三、底模板与定稿模板

| 文件 | 角色 |
|---|---|
| `pattern/_base_vendor_L770.pieces.json` | **底模板**（厂商基准男 M，L=770），**只读**，几何未改 |
| `pattern/_tpl.pieces.json` | **定稿模板** `shuling-v1`：5 片 / canvas 1570×2049.292 / `collar` 块记段·共边·端头·面积·自交 |
| `pattern/_tpl.svg` | 模板 1:1 图 |

模板结构对齐 `_base_vendor_L770.pieces.json`（`params / resolved / canvas / pieces`，每片带 `ox/oy/box/cmds/grain`），
另加 `_note / version / source / collar`。

> 坑：`sheet.write_sheet()` 会顺带写同名 `.pieces.json` sidecar，增强模板必须在它**之后**落盘；
> `make_png()` 的 HTML 在 `out/`，SVG 必须同目录否则白图（模板 SVG 先写 `out/` 再复制回 `pattern/`）。
