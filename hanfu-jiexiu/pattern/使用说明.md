# 使用说明 · 对穿交接袖（默认口径）

和 `../hanfu-cad` 是同一件衣身：**衣身一律不动**，只在袖上加一道接袖缝 ＋ 4 片 330×222，
通袖因此变成 1630（＝(肩点 285 ＋ 衣身袖 200 ＋ 接袖 330) × 2），袖口收窄到 130（掩腕）。

## 一、一条命令出图

```bash
cd pattern

python make.py --sex 女 --size M          # 单码
python make.py --sex 女 --all             # 整档 XS~2XL
python make.py --sex 男 --all             # 男装（vendor 档，同一套板型 5 个码）
python make.py --sex 女 --size M --profile artifact     # 换基准
python make.py --sex 女 --height 163 --bust 86          # 直接给净尺寸
python make.py --sex 男 --size M --ease 宽松            # 放量档
python make.py --sex 女 --all --out ../out              # 指定输出目录

# 旋钮：在号型推导值上覆写；未知键直接报错，不会静默无效
python make.py --sex 男 --size M --params '{"L":860,"JS":300,"WRIST":140}'
# 只打印当前参数表（JSON）—— 界面滑杆与外部工具拿它当基准
python make.py --sex 男 --size M --dump-params
```

**参数键**＝`pattern/sizing.py::params()` 返回的字典：
`L / W_HEM / OV / Y_ARM / SLEEVE_LEN / JS / CUFF / WRIST / NECK / COL_W / X_ARM / X_SHLD /
HEM_RISE / EASE / TILT_DEG`。`--params` 只改值、不改几何算法（几何仍是 `build.py` 那一套）。

产物 `out/<profile>_<性别>_<码>/`：

| 文件 | 内容 |
|---|---|
| `对穿交_接袖_<性别>_<码>.svg` | 裁片图，mm，六图层 |
| `对穿交_接袖_<性别>_<码>.dxf` | CAD 图，mm（`INSUNITS=4`），五图层 |
| `…pieces.json` | 几何侧车（父程序排料 / 二次开发用） |

另在 `out/尺码表_vendor_男装.md` 汇总各码尺寸。

## 二、两套基准

| 性别 | 自动基准 | 依据 | 中码（M） |
|---|---|---|---|
| **女** | `artifact` | 钱樟墓文物复原（旧 v6 半臂，本版未跟进接袖，仅留档） | 衣长 825 ｜ 平胸 822 ｜ 摆宽 1150 ｜ 袖口 195 ｜ 领缘 40 |
| **男** | `vendor` | 厂商实物出货表（最高置信度） | 衣长 800 ｜ 平胸 570 ｜ 摆宽 798 ｜ 通袖 1630 ｜ 袖根 204 → 腕口 130 ｜ 领缘 70 |

`--profile` 不填按性别自动选。**男女同款请统一用 `--sex 男`（vendor 档）**。
厂商表缺的三项：下摆 ＝ 胸宽×1.40（已确认正确）、腋深 ＝ 衣长×0.36、交叠 270。

## 三、DXF 图层与净版

| 图层 | 内容 | 颜色 |
|---|---|---|
| `CUT_轮廓` | 裁片净样闭合多段线 | 白/黑 |
| `GRAIN_布纹` | 布纹线（带箭头） | 灰 |
| `NOTCH_刀口` | 对位刀口 | 红 |
| `TEXT_文字` | 片名 × 数量 | 绿 |
| `DIM_标注` | 100 mm 校验标尺 | 青 |

**净版：未含缝份**，裁布自行加放（下摆 2–3 cm、侧缝 1 cm、领缘 1 cm）。打印后先量标尺，误差应 ≤0.5 mm。

## 四、尺码从哪来

- 档差：GB/T 1335.1/.2-2008（身高 5 cm、胸围 4 cm 分档；女中间体 160/84A、男 170/88A）
- 放量：女 8–10 cm 合体 / 男 20–22 cm 合身 —— **单一来源，置信度低**
- 每个参数的出处与置信度见 `verification/尺码资料核验.md`；硬口径：同一篇文章多站转载只算 1 个来源
- 基准：女 M（160/84A 合体）＝ 已过审的 v6 半臂，其余码从它推；`--sex 女 --size M` 与 v6 逐项一致，
  可当回归测试用

## 五、可调的量（`pattern/sizing.py` 顶部）

| 参数 | 含义 | 现值 |
|---|---|---|
| `HEM_ADD` | 衣长略加（只加下摆，腋点不动） | 30 |
| `BODY_SL_RATIO` | 接袖缝位置：衣身袖长 /(通袖半 − 肩点) | 0.1885（M → 衣身 100 ＋ 接袖 430，总袖长不变） |
| `NECK_PRE` | 预开领总宽 | 100 |
| `WRIST_DROP` | 腕口 ＝ 袖口 − 该值 | 30 |
| `COL_W` | 领缘宽 | 70 |
| `EASE` | 紧身 / 合体 / 宽松 系数 | 0.94 / 1.00 / 1.08 |

袖底缘、袖根、腕口是**几何锁定**的（袖底为一条直线）：
`袖根 = 腕口 + 接袖长 × (tan 袖底角 + tan 落肩角)`。要改袖根就改腕口或接袖长。
想让接袖缝更靠身 → 调小 `BODY_SL_RATIO`；它按比例走，换码时接缝在袖上的相对位置不变。

## 六、回归自检

```bash
python ../verification/verify_接袖.py ../out/vendor_男_M/对穿交_接袖_男_M.pieces.json   # 27 项
python assembly.py --sex 男 --size M     # 拼合平铺图（看袖长 / 接缝连续性）
python preview.py 男 M                   # PNG 预览（Edge 无头，1:1）
python sizing.py                         # 打印男女全码尺寸表
```

实测：S / M / L / XL / 2XL **27 项全 PASS**（2026-10-29）。

## 七、没做

- **DWG 脚本直出**：`DXF` 可直接在 AutoCAD 打开另存；要脚本直出 DWG 得装 `pywin32` 走 AutoCAD COM，
  本仓不做（会绑死某台机器的安装路径）。
