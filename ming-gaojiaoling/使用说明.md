## 一、构造：后片直接调「谱系父」的函数

`geo.pieces(d)` 不再读 `_template_back.json` 的坐标数组，改成

```python
_jx = jiexiu_params(d)                       # CASE → 接袖版参数字典
back = construct.back_half(construct.derive(_jx, "seam"))
```

- **`construct.py`** 是接袖版（谱系父）的纯函数构造：吃参数、返回裁片，没有 IO。
- 明制只负责「把 CASE 翻成父版型的参数」＋「前片 / 续衽 / 领缘条」；
  后片的形状、摆弧、腋下圆角、袖底直线全部沿用父版型，父版型一改它就跟着改。
- `_template_back.json` / `_template_all.json` 降级为**离线段快照**（留档对照用，
  已不参与出图）。

**口径**：`SEAM_H`（袖根，标准图实测 208）是**输入**，腕口高是**派生**
（`seam_mode="seam"`：袖底直线过腋点与「袖口上缘 − 袖根」，延长到腕口，反解腕口高
＝131.3，标准图 130，差 1.3mm）。反过来锁腕口会把袖根逼到 202.6，差 5.4mm——
取误差小的那一侧。

## 二、整体数学约束（`construct.constraints(d)` 可逐条量）

| 约束 | 状态 |
|---|---|
| 袖底共线：腋点 → 接袖根下缘 → 腕口下角 三点共线 | Δ0.000 |
| 袖根 = 袖口上缘 − 袖底在接袖缝处的高度 | Δ0.000 |
| 通袖 = 2×(肩点 + 衣身袖 + 接袖) = 2210 | Δ0.000 |
| 摆半宽 = 摆宽/2×放量 = 585 | Δ0.000 |
| 门襟斜角由 (NECK/2, L)→(LAP_DX, 0) 派生，不写死角度 | Δ0.000 |

跑一遍：

```bash
python -c "import sys; sys.path.insert(0,'pattern'); import geo, construct; \
d=geo.derive(geo.CASE); print('\n'.join(construct.report(construct.derive(geo.jiexiu_params(d),'seam'))))"
```

## 三、旋钮（studio 参数面板，8 个）

| 键 | 名称 | 范围 |
|---|---|---|
| `L` | 后中长 | 700–1000 |
| `HALF` | 摆半宽 | 450–700 |
| `DARM` | 腋深 | 260–420 |
| `RISE` | 下摆起翘 | 40–140 |
| `X_SH` | 肩点 | 480–650 |
| `SLV` | 衣身袖长 | 180–360 |
| `SEAM_H` | 袖根（接缝处袖高） | 160–280 |
| `NECKW` | 领口宽 | 70–130 |

命令行同一套：`--params '{"HALF":620,"RISE":110}'`；`--dump-params` 打印当前基准。

**不挂旋钮的量**：`JS`（接袖长）、`CUF`（袖口高）、`XUREN`、`LAP`、`COL_W`——
测过 8% 扰动，产物一个字节都不变（本版没有接袖片 / 袖口边，领条宽是高交领硬约束
97.05）。挂上去只会变成假滑杆。
