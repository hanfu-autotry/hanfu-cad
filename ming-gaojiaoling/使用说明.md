# ming-gaojiaoling · 明制高交领（默认口径子程序）

用户手绘标准图（尺寸）＋ 谱系图（形制）逆向出来的版型，单号「本案」。注册 id `minggaojiaoling`。

```bash
python pattern/make.py --size 本案 --out out
python pattern/verify.py            # 形状自检（18 项对表全 0 差）
python pattern/make.py --params '{"HALF":620,"RISE":110}'
python pattern/make.py --dump-params
```

## 一、构造：后片直接调「谱系父」的函数

后片不再搬 `_template_back.json` 的坐标数组，而是调接袖版（谱系父）的纯函数构造：

```python
_jx = jiexiu_params(d)                       # CASE → 接袖版参数字典
back = construct.back_half(construct.derive(_jx, "seam"))
```

- **`construct.py`**：接袖版的纯函数构造，吃参数、返回裁片，没有 IO。
- 明制只负责「把 CASE 翻成父版型的参数」＋「前片 / 续衽 / 领缘条」；
  后片的形状、摆弧、腋下圆角、袖底直线全部沿用父版型 —— 父版型一改它就跟着改。
- `_template_back.json` / `_template_all.json` 降级为**离线段快照**（留档对照，不参与出图）。

**口径**：`SEAM_H`（袖根，标准图实测 208）是**输入**，腕口高是**派生**
（`seam_mode="seam"`：袖底直线过腋点与「袖口上缘 − 袖根」，延长到腕口，
反解腕口高 ＝ 131.3，标准图 130，差 1.3 mm）。反过来锁腕口会把袖根逼到 202.6（差 5.4 mm）——
取误差小的那一侧。

## 三、旋钮（9 个）

| 键 | 名称 | 范围 |
|---|---|---|
| `L` | 后中长 | 700–1000 |
| `HALF` | 摆半宽 | 450–700 |
| `DARM` | 腋深 | 260–420 |
| `RISE` | 下摆起翘 | 40–140 |
| `X_SH` | 肩点 | 480–650 |
| `SLV` | 衣身袖长 | 180–360 |
| `SEAM_H` | 袖根（接缝处袖高） | 160–280 |
| `NECKW` | 领口宽 | 70–130 |
| `XUR_H` | 续衽 H 移动量（HH1 新左边缘） | 0–200（标准 20） |

**续衽 H / HH1（2026-11-18 定，2026-11-26 收口）**：H 是 **l′ 定位弧**上的动点，自 `P2′` 沿弧向中缝方向
移动 `XUR_H`；过 H 作**平行于原左外缘**（摆角→P2′）的直线，落到下摆得 `H1`；`HH1` 就是**新的续衽左边缘**。

> **l′ 不再出现在裁片边上**：2026-11-26 起领口线统一为 L，原来沿 l′ 冒出、被领条包裹的那一节
> （长 485.7、高 68）与曲边三角形（1392 mm²）全部删除。l′ 只剩一个作用：**定位 H**，决定 HH1 落在哪儿。

**续衽上缘由领条缘派生（2026-11-26 第二次）**：`P1′` ＝ **L 与中缝所在直线（x=0）的交点** ＝(0, 715)；
过 P1′ 作**平行于水平面**的直线，截领条外缘 `Γ_C = { |X−o| = R−C }` 得 `X(−108.346, 715)`；
`L′ = Γ_C 弧（A′→X 331.6）＋ 水平段（X→P1′ 108.3）＝ 439.9`，左缘 `A′→H1 = 516.4` 仍走 HH1。
`A′(−387.701, 547.555)` 就是领条端面 `[A, A′]` 的上端 ⇒ 续衽的左上角与领条端面严丝合缝。
**C 一变，L′ 跟着变**——不再有「领口线一套、续衽上缘另一套」。

`XUR_H=0` 时 H＝P2′、H1＝摆角，退回原外缘版（面积 301946.7）；标准 `XUR_H=20` 时 HH1＝492.93
（H→H1）、H 到原外缘垂直距 17.40，续衽面积 **293107.8**（裁掉 8839.0，2.93%）。
被裁掉的原外缘与那段下摆在裁片图里画成**灰色辅助线**留档。

**「高位接衽」＝工艺优化类描述（不是构造条款）**：续衽上端一直做到**领条外缘**（而非只做到缝线 L），
布片在领带底下有料、缝合时不至于缩到缝线以下——这是**工艺上**的说法。
几何上只认一条：续衽上缘 `L′ = Γ_C 弧（A′→X）＋ 水平段（X→P1′）`（见上），代码里不出现「高位接衽」字样。

**领条同步**：领缘的起点＝**新左边缘 HH1 与领口线（l 圆）的交点 P0**（旧版门襟边＝原外缘时 P0＝P2），
`领条长 = 2×(P0→颈侧点 l 弧) + 后领段`：标准 20 时 P0＝(−423.587, 453.649)、弧长 659.245、
领条 1487.5 → **1448.5**；`XUR_H=0` 时回到 1487.5（P0＝P2，连续）。领宽仍＝AA′＝PB＝**97.1**（不变）。
A／A′／B 仍是领宽的构造依据，基准为原门襟线（图上灰辅助线）。

**平铺图的领子（2026-11-18 定稿，数学口径）**

记 o、R＝l 圆圆心/半径，L＝P.y，C＝领宽，A＝P0＝HH1∩Γ_L，û＝(H−H1)/|H−H1|。

| 量 | 定义 |
|---|---|
| 反解领宽 | `ox² + (k+C)² = (R−C)²`, k＝L−oy ⇒ **C = (R²−ox²−k²)/(2(k+R)) = 86.711** |
| 内缘 Γ_in | `{o + R(cosθ,sinθ): θ∈[θ_A,θ_P]} ∪ [(P.x,L),(−P.x,L)] ∪ mirror`，长 2×659.245+130 = **1448.49** |
| 上缘 Γ_out | `{o + (R−C)(cosθ,sinθ): θ∈[θ_A″,θ_top]}`，θ_top↦(0, L+C)；⇒ `∀X∈Γ_out: |X−o| = R−C` |
| 端面 | `[A, A″] ⊂ HH1`，A″＝HH1∩Γ_C；|A A″|＝**100.53** |
| 后中点 | 内缘过 (0, L)＝(0,845)；上缘汇于顶点 (0, L+C)＝**(0, 931.71)** |
| 人字腿 | ∀s∈{±1}: 线段 [ (s·65, 845), (0, 931.71) ]，长 108.37 |
| 领条 | **1448.50 × 86.70**；|Γ_in| = 领条长（差 0.02＝折线采样） |

实测：A＝(−423.59, 453.65)、A″＝(−387.70, 547.55)、P＝(65,845)。

`python pattern/verify.py` 相关自检：`前片/续衽上缘在 L 圆上`、`A、A′ 在 HH1 上`、`AA′＝领宽`、`PB＝领宽`、
`外缘同心于内缘`、`L′ 整条在领带内`、`两半缝线长＝领条长`。

**不挂旋钮的量**：`JS`（接袖长）、`CUF`（袖口高）、`XUREN`、`LAP`、`COL_W` ——
8% 扰动实测产物一个字节都不变（本版没有接袖片 / 袖口边；领条宽由 L 反解＝86.711，不吃输入），
挂上去只会变成假滑杆。
