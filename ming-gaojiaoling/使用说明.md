## 参数级调版（与分裁其它版型同一口径）

```bash
python pattern/make.py --size 本案 --params '{"L":860,"JS":300}' --out out
python pattern/make.py --size 本案 --dump-params      # 打印 CASE（JSON）
```

覆盖的是 `pattern/geo.py::CASE` 的数值项；未知键直接报错。

**当前口径**：`pieces()` 的裁片几何取自 jiexiu 模板（`_template_back.json` 的 `params`），
CASE 只进 `derive()` 得到的 `d`（标注 / 平铺线稿）。要让 CASE 直接驱动裁片，
得把 `pieces()` 里的 `TPL["params"]` 换成 `d`——那会改变现有产物，属结构级改动，需先确认。

**模板已随接袖版改（2026-11-09）**：jiexiu 的衣身袖长砍半、总袖长不变
（`SLEEVE_LEN` 265 → 132.5、`JS` 265 → 397.5），`_template_back.json` / `_template_all.json`
已按新 jiexiu 后片重新导出。本版后片的袖根竖边因此从 x=550 前移到 **x=417.5**，
前片/续衽/领缘条（1178.3×97.1）几何不变。重新导出方法：跑 `hanfu-jiexiu/pattern/build.py`
（默认 `_DEF`）→ 取 `pieces.json` 里的「后片半」写回模板。
