# 版型几何：数学化逐步构造 + 通用打版

> 本版由 2026-11-08 明制高交领那轮交互覆写。核心不是「怎么画得像」，而是
> **把一个图形问题拆成可判真假的几何命题，逐个求解、逐个复核**。

---

## §0 五条铁律

1. **听指挥，逐步构造**。用户给一个点、一条线，就只做这一步。不预判整体、不补全、
   不「顺手把领子也画了」。跳步做出来的一定要回滚。
2. **辅助层自由，几何层冻结**。构造线画在平铺线稿上；`geo.py::pieces()` 是裁片，
   只有用户明说「写入裁片」才动。用户说「千万别动裁片」时，连重跑 make.py 都要避免
   （只调 `flat.write()`），因为 DXF 会被重写。
3. **先给量分类，再动算**：哪个是**给定量**、哪个是**约束条件**、哪个是**待求量**。
   把待求量当约束、或把约束当给定量，是整个模型报废的头号原因（§5）。
4. **多解必须有数学判据**，不许按「看着顺」「离得近」挑（§4）。
5. **每步都留可复核的数值证据**，交付前必须把图渲染出来自己看一遍（§8）。

---

## §1 逐步构造协议

用户处于「我给点，你照做」模式时：

- 一步一交付，图面只出现本步要求的点/线；多余辅助线（定位圆、细实线）一律不留。
- **先判断几何关系，通过 askuser 审核，再照图做**——但用户已经给了明确几何指令时不要反问，
  直接做，把判断依据写在回复里让他一句话能否掉。
- 有歧义时**先算，再列表**：把所有候选模型的数值都算出来摊给用户，
  而不是猜一个做下去（本次三种 PB 模型对照表直接终止了一轮错误方向）。
- 用户自我否定（「我的这次思考有误」）→ 立刻回到上一版，不争辩、不保留废稿。
- 口径反复修正时，只改口径/常量，不要碰已确认的几何（§9）。
- 术语先锚定、依托谱系/实物，不凭先验归到「最像的那一类」。

## §2 两层分离

| 层 | 文件 | 内容 | 可否自由改 |
|---|---|---|---|
| 辅助层 | `flat.py` → `平铺线稿.svg` | 构造点、构造线、整圆、镜像同步 | 可以 |
| 几何层 | `geo.py::pieces()` → 裁片 SVG/DXF/JSON | 正式裁片表 | 需显式指令 |

- **实线＝切线，虚线＝辅助/折线**。用户说「中缝改实线」意思是**沿中缝切开**，不是改线型。
- 切开后中缝是两片共用的轮廓边，不要再在片内画一条中缝线。
- **外襟与内襟每一步同步**：内襟＝外襟整体镜像（`x → −x`，连 `marks`/`aux` 一起镜像）。
- 「裁片对上了再拼图」：默认只出裁片，`--asm` 才出拼合图。

## §3 几何原语（可直接抄）

坐标：x=0 中缝、y=0 下摆、y 向上；单位 mm；SVG 输出时 `y_screen = oy − y`。

```python
def circle3(A, B, C):
    """三点定圆 -> (Ox, Oy, R)"""
    ax, ay = A; bx, by = B; cx, cy = C
    d = 2.0 * (ax*(by-cy) + bx*(cy-ay) + cx*(ay-by))
    Ox = ((ax*ax+ay*ay)*(by-cy) + (bx*bx+by*by)*(cy-ay) + (cx*cx+cy*cy)*(ay-by)) / d
    Oy = ((ax*ax+ay*ay)*(cx-bx) + (bx*bx+by*by)*(ax-cx) + (cx*cx+cy*cy)*(bx-ax)) / d
    return Ox, Oy, math.hypot(ax-Ox, ay-Oy)

def inter(c0, r0, c1, r1):
    """两圆求交 -> 0/1/2 个点"""
    dx, dy = c1[0]-c0[0], c1[1]-c0[1]
    D = math.hypot(dx, dy)
    if D < 1e-9 or D > r0+r1 or D < abs(r0-r1):
        return []
    a = (r0*r0 - r1*r1 + D*D) / (2.0*D)
    h = math.sqrt(max(0.0, r0*r0 - a*a))
    ux, uy = dx/D, dy/D
    bx, by = c0[0]+a*ux, c0[1]+a*uy
    return [(bx-h*uy, by+h*ux), (bx+h*uy, by-h*ux)]

def wrap(t):                       # 角度归一到 (-pi, pi]
    return math.atan2(math.sin(t), math.cos(t))
```

- **圆弧的「平行线」＝同心圆**（半径差），不是平移；`l′ = l` 的平行上移同理。
- 三点圆弧转贝塞尔：每 1/4 圆用 `k = 4/3·tan(Δθ/4)·R` 定控制柄；
  `arc3()` **末点强制咬死目标点**，否则轮廓闭不上。
- 精确切分用 **de Casteljau**，不要采样近似。
- 端线不一定沿法向：本次 `AA′` 是沿「摆角→P2 的外缘延长线」量的，
  所以 `半径差 (R−R2=82.29) ≠ 领宽 w (=97.05)`。**别把斜向量当径向宽**。

## §4 ★ 多解选择：全等三角形 + 同向角偏移

两圆求交必有两个解，随手挑一个后面全错。判据要从**已有构造的全等关系**里长出来。

本次：`A=P2`、`P=颈侧点` 都在 L 圆上（半径 R）；`A′`、`B` 都在 L2 圆上（半径 R2）；
且 `AA′ = PB = w`。于是

```
|OA| = |OP| = R ,  |OA′| = |OB| = R2 ,  |AA′| = |PB| = w
⇒  △OAA′ ≌ △OPB  (SSS)  ⇒  ∠AOA′ = ∠POB
```

**判据：B 取与 A′ 同号角偏移的那个解。**

```python
dA = wrap(atan2(Ap[1]-Oy, Ap[0]-Ox) - atan2(A[1]-Oy, A[0]-Ox))
aP = atan2(P[1]-Oy, P[0]-Ox)
B = next(q for q in cands
         if wrap(atan2(q[1]-Oy, q[0]-Ox) - aP) * dA > 0)
```

实测（领宽 110）：两解角偏移 `+6.92° / −6.92°`，取 `+6.92°` 得 `B=(-8.67, 881.68)`；
另一个 `(-43.20, 780.21)` 是反向解。取反后领条两端不对应同一条平行弧。

> 通则：**用「角偏移同号」这类不变量选解，不要用距离、象限或视觉顺眼度。**
> 构造里若是 SSS/SAS 全等，直接把对应角搬过去，连求交都可以省。

## §5 ★ 约束识别与参数反解

先写清三件事，再解方程：

| 角色 | 本次 | 说明 |
|---|---|---|
| 给定量 | `A=P2`、`P=颈侧点`、L 圆心/半径 | 由裁片几何钉死 |
| 约束条件 | **领宽恒等于 AA′**（`PB = AA′ = w`）；B 落中缝 `x=0` | 用户明确指定 |
| 待求量 | `w`、A′、B、R2 | 由约束反解 |

**单自由度二分模板**（先扫描确认变号与单调，再二分）：

```python
def solve(lo=80.0, hi=125.0):
    flo = f(lo)                       # f(w) = B(w).x
    for _ in range(80):
        mid = (lo+hi)/2
        if f(mid)*flo > 0: lo, flo = mid, f(mid)
        else:              hi = mid
    return (lo+hi)/2
```

本次 `f(80)=+11.42`、`f(110)=−8.67`、`f(125)=−18.72`（单调递减），
根 `w = 97.05141`，`B=(0, 872.069)`，`R2=455.098`。

**三种模型必须分开算，别混**：

| 模型 | 结果 |
|---|---|
| `PB = AA′ = w`，反解使 B 重合 | `w = 97.05141` ✅ 采用 |
| `PB` 固定 110，只调 AA′ 使 B 重合 | `AA′ = 101.22741`，`PB = 110` |
| 两 L2 圆相切（带子光滑） | `w = 111.030`，`PB = 184.919` |
| 领宽 110、B 为两 L2 交点 | `PB = 159.756 / 210.586` |

> 用户一度怀疑「PB 未必等于 AA′」，把上面全算出来后自己否定，回到原模型。
> **不要替用户合并模型，也不要偷偷固定一个量**。

## §6 ★ 可达性 / 范围检查（最快的模型证伪）

动手画之前先算**坐标范围**，能提前发现「模型本身错了」：

- 左 L2 圆心 `Ox=−443.738`、半径 `R2≈455` ⇒ `x ∈ [−898.7, +11.3]`。
- 而颈侧点 `P.x = 65`。**B 根本到不了 x=65**，所以只要坚持「L2 是过 A′ 的同心圆」，
  就做不出实物（M1:S8，领口宽 20cm）那种有宽度的后领段。
- 两圆有交的充要条件：`|r0−r1| ≤ D ≤ r0+r1`。每次求交前先验一遍，无交时返回空而不是崩。

这比渲染一张图再「看着不对」快一个数量级。**范围算不出来，就说明该怀疑模型，不是怀疑画图。**

## §7 从构造线反推裁片

1. 闭合轮廓 = 外弧 `L`(A→P) → 端线 `PB` → 内弧 `L2`(B→A′) → 端线 `A′A`，
   用 `arc3()` 生成两段弧、`M/L/Z` 收口；`_segs()` 验起点＝终点。
2. **裁片形状由计算/实物决定，不预设长方形**。用户说「我不确定是不是长方形，总之算出来就是」
   时，就把依据和备选都列出来，别把猜测写成事实。
3. 领条长度反推：`领口线 = 2 × L弧 + 后领水平段`（本次 `2×524.2 + 130 = 1178.3`）；
   备选：中线 `1033.1`、内缘 `887.8`（B 重合时内缘后领段长为 0）。
4. **B 重合 ⇒ 左右两段接成一条连续带子 ⇒ 全衣只有一条领条，`qty=1`**。
   用户明确否掉过 `qty=2`。
5. 写入 `pieces()` 时带 `dims`（长/宽标注）、`grain`、`note`（反推依据），
   并同步改图签标题与说明条数。

## §8 实测与自检

每步都要能从产物反读出证据：

- 从生成的 SVG **正则反读红线段端点**，`hypot` 量长：本次 `AA′×2 = 97.11`、`PB×2 = 97.07`
  （0.1mm 取整误差）；两条 PB 终点同为 `(1300.0, 527.9)` ⇒ **重合误差 0.000000**。
- 轮廓闭合：`_segs()` 的起点＝终点；`arc3()` 末点强制等于目标点。
- **证明「没动裁片」**：对裁片 SVG / pieces.json 取 md5 前后对比；
  DXF 若变化，导出两次定位差异到 `$TDCREATE` 时间戳即可证明几何未变。
- **viewBox 留白**：整圆顶部若落在页面 y<0，把 `viewBox` 上边界抬到 `−150`，
  否则「不截断」在视口上仍被裁。
- **交付前无头渲染 PNG 自己看**：白底、线宽在目标画幅下不消失、文字不互相遮挡、
  整圆不被裁。只说「文件已生成」就交付是事故。
- 用户看不到改动时：md5 比对输出文件、另存 `_v2.svg` 绕开缓存；
  查 `geo.py` 是否有**函数被定义两遍**（后一份覆盖前一份，症状是「改了没效果」）。

## §9 口径反复修正时的处理

- 每次修正只改**口径与常量**，保留已确认的几何；把数值和口径一起写进常量 + 注释。
- 本次口径链：`横卧领 → 高交领`、`qty=2 → 全衣一条`、`B 必定重合 → 不一定重合 → 回到重合`、
  `领宽 110 → 97.1`。每次都先回滚未接线代码，再改，最后才「写入裁片」。
- 长期口径写 `{workspace}/.workbuddy/memory/MEMORY.md`（项目需求唯一来源），
  当日日志逐条追加，过时口径明确标「作废」而不是删掉。

## §10 工程基线（沿用，勿丢）

- **量纲锚定**优先级：尺寸标注 > 网格 > 图内已知物 > 人体比例；无锚点标 `UNSCALED`。
  做各向异性检验（横纵比例差 ≤2%）。**「围」与「净平」差 2 倍**，标注 13 可能是围 130。
- **曲线规范**：直线段保持真直线；曲率明确段用三次贝塞尔；
  两段相接用 G1 三次混合（k≈0.92）；精确切分用 de Casteljau。折线近似会让用户说「太棱角分明」。
  新增路径命令必须同步 `path_d()` / 采样 / 校验器**三处**，漏一处曲线静默丢失。
- **像素叠合闸门**：官图掩膜（膨胀→洪泛→腐蚀→最大连通域）+ 按真实拼合关系摆片 +
  IoU 最大化配准；IoU ≥0.90 优 / 0.85–0.90 合格需说明残差 / <0.85 不通过。
  残差**按面积排序**并做敏感度测试，别按视觉醒目度。
- **先 SVG 后 CAD**：SVG 是主产物、DXF 是派生物；三件套 `.svg/.dxf/.pieces.json` 必须同一次 build，
  禁止手改其中一份；出 DXF 后做跨格式对账（逐片 bbox、闭合性、刀口数、图层数 ≤0.1mm）。
- **DXF**：`doc.units = MM`；图层分离 `CUT_轮廓/GRAIN_布纹/NOTCH_刀口/TEXT_文字/DIM_标注`；
  中文必须 `doc.styles.add("CN", font="simsun.ttc")`，否则全是 `?`。
- **推档**：GB/T 1335.1/.2；厂商实物尺码表 > 网络资料（转载只算 1 个独立来源）；
  图纸文字标注换码不会自动变，**任何写死数字的文案都是 bug**。
- **坑**：重复函数定义、硬编码文案、按视觉挑多解、跳过 SVG 直接出 DXF、
  误解一句「去掉袖片」连做三版（正确做法是回上一存档点、只加最小补丁）。

## §11 形制沉淀

**对穿交**：= 直领对襟的剪裁 + 交领的穿法（二次成型），不是把交领裁出来。
实物基准：无锡七房桥钱樟夫妇墓 · 鸟衔花枝纹缎夹袄。
原件左衽，**改右衽不改变裁片**（两襟同形镜像）。半臂化 = 去掉独立袖片，不是通袖一片。

**明制高交领**（本次）：
- 后片照 jiexiu 模板原样，**不挖后领**；前中缝竖直居中，左右对称。
- 交襟靠续衽沿竖直前中缝**直拼**，斜的是续衽外缘（门襟边）。
- 下摆 S1/S2 是以中缝为轴互为镜像的两段，天然等长，**不需要量、不需要反解**。
- **高交领，不是横卧领**（旧「40 宽平贴不立起」口径作废）。
- 领缘条全衣一条、长方形 `1178.3 × 97.1`；宽＝AA′＝PB＝97.05141（B 落中缝重合反解）；
  长＝2×L弧(524.2)＋后领段(130)。模板 `1908×40` 只是旧值。
- 实物 M1:S8（宁夏盐池冯记圈明墓）：领口宽 20cm、领高 13.5cm —— 结构上有宽度的后领段，
  是「B 是否必须重合」争论的来源。
