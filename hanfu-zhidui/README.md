# hanfu-zhidui · 直领对襟（默认口径子程序）

单号「本案」。以 `../hanfu-cad`（对穿交半臂）的裁片为底，**领襟口径完全参照**
`../hanfu-shenyi/pattern/build.py`（原始直领交襟衣 V1）的 `_DEF` —— 用 `ast` 读它、不执行它，
所以那份程序改口径，这边跟着变。

> 子程序之一，口径＝**默认**。父程序在 `../hanfu-studio/`，注册 id `zhilingduijin`。

## 两步（逐步绘图）

**① 起手**：在现有模板上移除所有，只留**领条**与**后片**；再把后片复制一份命名**前片**。
几何一处未改。

**② 开领宽 ＋ 装领条**（照 V1）：

| 量 | 值 | 来源 |
|---|---|---|
| 开领宽 | **160** | V1 `SLIT_HALF` 80×2 —— 前片沿中缝侧**全高**切掉 80 |
| 领条压边 | **40／边** | V1 `LAPEL_FOLD`（＝领条在剪口线上可见的宽） |
| 中间露出后片 | **80** | 160 − 40×2 |
| 后领立起 | **77**（底 160 → 顶 89） | V1 `NECK_H` ／ `NECK_TOP_HALF` 44.5×2 |
| 领条宽 | **95** | V1 `COLLAR_W` |

**领条长**（这是当初画错、被指出的地方）：
领条是一条直的整带，成型后倒 U（左前襟 → 绕后颈 → 右前襟）

```
长 ＝ 2 × 前片剪口边长 ＋ 后领段（＝开领宽）
   ＝ 2 × 821.97 ＋ 160 ＝ 1803.93
```

立起的梯形是**带子的宽度立起来**，不额外吃长度：可见高 77 ≤ 带宽 95；
顶边 89 比底 160 短，是内侧转弯变短。两条 notch 打在前襟段两端（821.97 / 981.97）。

> 模板那条 1850×40（notch 825/1025 → 后领段 200）是**对穿交半臂**的口径，与开领宽 160 对不上、
> 宽度也不够压边，已作废。

## 平铺（正面线稿）

`flat.py` 只画**正面**、**线稿**（白底纯黑，不填色、不做背视）：
外轮廓＝后片整片；中央四条线＝剪开线 ±80（粗）／领条内边 ±40（细）；
后中缝虚线只到下摆→肩线；**顶边在 ±40…±80 断开**（领条从那里横跨）；
**转折处**＝外缘 ±80 斜收到 ±44.5（高 77）＋ 顶边 89，而**内缘 ±40 一直直通到顶**。

## 文件与产物

```
pattern/geo.py     模板只读加载 ＋ V1 的 _DEF ＋ 开领裁切（de Casteljau，曲线不退化成折线）
pattern/step1.py   第 1 步：只留领条与后片、后片复制成前片
pattern/step2.py   第 2 步：开领宽 ＋ 装领条（顺带出平铺线稿）
pattern/flat.py    平铺正面线稿
pattern/make.py    studio 入口（kind=make，4 旋钮 NECK_W / COLLAR_W / LAPEL_FOLD / NECK_H）
pattern/sheet.py   裁片图排版器（拷自 ming-gaojiaoling）
pattern/直领对襟_本案.svg / .pieces.json   定稿产物
out/               step1 / step2 过程稿 ＋ 平铺预览
```

```bash
python pattern/step2.py                                   # 裁片图 ＋ 平铺线稿
python pattern/make.py --sex — --size 本案 --out pattern  # 定稿产物
python pattern/make.py --params '{"NECK_W":180}'          # 改开领宽
```
