# hanfu-zhidui · 直领对襟（默认口径子程序）

单号「本案」。以 `../hanfu-cad`（对穿交半臂）的裁片为底，**领襟口径完全参照**
`../hanfu-shenyi/pattern/build.py`（原始直领交襟衣 V1）的 `_DEF` —— 用 `ast` 读它、不执行它，
所以那份程序改口径，这边跟着变。

> 子程序之一，口径＝**默认**。父程序在 `../hanfu-studio/`，注册 id `zhilingduijin`。

## 两步（逐步绘图）

**① 起手**：在现有模板上移除所有，只留**领条**与**后片**；再把后片复制一份命名**前片**。
几何一处未改。

**② 开领宽 ＋ 装领条**（照 V1）：

| 量 | 值 | 来源 |
|---|---|---|
| 开领宽 | **160** | V1 `SLIT_HALF` 80×2 —— 前片内边＝**弦 P→Q**（P＝领口点 (±80, L)，Q＝下摆曲线∩中缝 (0,0)）；前片 ＝ 后片半 − △(Q,(0,L),P)，面积差 80×825/2 ＝ 33000 |
| 中间露出后片 | **100** | 160 − 30×2（领条压在前襟边上） |
| 后领带顶边 | **105.54** | 带宽 miter：顶宽 ＝ NECK_W − 1.8155×带宽 |
| 后领立起 | **＝领条宽**（30） | 用户 2026-11-18：立起高 ≡ 带宽，V1 的 77 作废 |
| 领条宽 | **30**（3cm） | 用户 2026-11-18 定；V1 的 95 作废 |

**领条长**（这是当初画错、被指出的地方）：
领条是一条直的整带，成型后倒 U（左前襟 → 绕后颈 → 右前襟）

```
|PQ| ＝ √(80² ＋ 825²) ＝ 828.87                （前襟边长，P=(80,825)、Q=(0,0)）
长   ＝ 2 × |PQ| ＋ 后领段（＝开领宽）
     ＝ 2 × 828.87 ＋ 160 ＝ 1817.74
```

后领立起高 NECK_H ≡ 领条宽（派生，不再单独挂旋钮），顶边由带宽的 miter 解出（105.54）。
带宽上限：顶宽 > 0 ⇒ 带宽 < (NECK_W/2)/0.9077（开领宽 160 时 88.1），超了 `params()` 直接报错。

两条 notch 打在前襟段两端（828.87 / 988.87）。

> 模板那条 1850×40（notch 825/1025 → 后领段 200）是**对穿交半臂**的口径，与开领宽 160 对不上、
> 宽度也不够压边，已作废。

## 平铺（正面线稿）

`flat.py` 只画**正面**、**线稿**（白底纯黑，不填色、不做背视）。领条按**纯几何**画（用户 2026-11-18 定）：

    LB ＝ 30（领宽 3cm）＝ 与襟缘（弦 c: Q→P）平行的等距带
    五块，共边＝折痕：
      前襟带 ×2   {Q, P, P+LB·n̂, Q+LB·n̂}        与 c 平行、宽 LB
      前片三角 ×2 {P, P+LB·n̂, M}                 转角折角
      后片梯形    {P, M, M′, P′}                 底 160 → 顶 105.5，高 LB=30
    M ＝ 过 P+LB·n̂ 且平行 c 的直线 ∩ y=L+LB ；M′ 镜像

两条前襟带的内缘在 y ＝ 155.4 处相交（下摆附近交叠），加顶部的后片梯形，平铺即「又」。
后中缝＝x=0 虚线（下摆→肩线）。

## 文件与产物

```
pattern/geo.py     模板只读加载 ＋ V1 的 _DEF ＋ 开领（内边＝弦 P→Q，下摆不截断）

pattern/sheet.py   裁片图排版器（拷自 ming-gaojiaoling）
pattern/直领对襟_本案.svg / .pieces.json   定稿产物
out/               step1 / step2 过程稿 ＋ 平铺预览
```

```bash
python pattern/step2.py                                   # 裁片图 ＋ 平铺线稿
python pattern/make.py --sex — --size 本案 --out pattern  # 定稿产物
python pattern/make.py --params '{"NECK_W":180}'          # 改开领宽
```
